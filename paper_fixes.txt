PART 1: PROJECT OVERVIEW & ARCHITECTURE (Technical Context)
--------------------------------------------------------------------------------

The AutoNorm project implements Adaptive Normalization in Transformers.
Core components in model.py and norm_selector.py:

* NormSelector: A lightweight gating mechanism using an MLP to dynamically
  blend Dynamic Transformer (DyT) and Layer Normalization (LN). 
  Formula: Output = w_DyT * DyT(x) + w_LN * LN(x)
* DyT: A learnable feature scaling (x * alpha).
* ResidualMLPBlock: Features Post-Norm architecture, LayerScale (init 1e-4),
  Squeeze-and-Excitation (SE), and DropPath.
* Training Pipeline (train.py): Includes EMA (Exponential Moving Average),
  MixUp/CutMix augmentation, and progressive finetuning (head then full).
